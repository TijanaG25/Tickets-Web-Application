# Tickets-Web-Application
The project involves the development of the Prime Tickets web application for online ticket sales and management of cultural events. The goal of the system is to digitalize the entire process – from user registration and login, through browsing and filtering events, to purchasing tickets and administrative system management.

The application is implemented using the PHP programming language for backend logic, a MySQL database for data storage, and HTML5, CSS3, Bootstrap, and JavaScript (jQuery and AJAX) technologies for the development of the user interface.

The system supports different types of users (guest users, registered users, and administrators), where each user type has clearly defined roles and permissions.

Through this project, practical knowledge in the fields of web programming, database management, session handling, data validation, and the implementation of security mechanisms in a web environment has been demonstrated.
